# 一、定义

不从"如何成功"思考，而从"如何必然失败"反向推演：找出所有通向失败的路，然后避开它们。Invert, always invert.

# 二、核心原理

失败模式的空间往往比成功模式小且清晰（成功的路径千差万别，死法屈指可数）；人对"避免痛苦"的敏感度高于"追求收益"，逆向清单的执行纪律更强。

# 三、解决什么问题

正向规划遗漏致命陷阱；决策标准模糊（"好"难定义，"致命"好定义）；风险清单靠正向想象总嫌不足。

# 四、适用场景

- 投资与高风险决策的筛选（无法排除致命项就弃投）
- 目标设定前的约束检查
- 与 Pre-mortem 配合使用：Pre-mortem 排序风险，Inversion 划红线

# 五、不适用场景

- 需要开拓性机会识别的任务——Inversion 防守有余、进攻不足
- 小决策——过度避坑导致不敢行动

# 六、使用方法

1. 反问："要保证这件事彻底失败，我该做什么？"列出完整清单
2. 反转成回避清单："所以绝对不做的是……"
3. 对每个不可回避的致命项，检查当前方案是否已有防线——没有防线的方案不合格
4. 芒格式筛选："我只想知道我会死在哪里，这样我就永远不去那里"——无法排除致命项的选项直接弃投

# 七、相关工具

逆向检查清单、失败模式清单、死地地图（已知失败区域汇总）。

# 八、实际案例

芒格投资流程：先假定企业五年后崩盘，倒推所有崩盘原因，无法排除则坚决弃投。见 `knowledge/06-案例库/`。

# 九、常见误区

- 只做逆向不做正向——Inversion 是过滤器，不是发动机
- 回避清单越攒越长，变成什么都不做的理由——区分"致命"与"不佳"
