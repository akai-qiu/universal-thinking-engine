# 一、定义

不依赖类比和惯例，把问题还原到不可再分的底层事实与约束，从事实本身向上推导结论。

# 二、核心原理

追问链条："为什么这样做？"→"因为一直是这么做的"→"这个做法当初服务于什么约束？"→"该约束现在还存在吗？"若约束已消失而做法还在，就找到了优化空间。

# 三、解决什么问题

打破"为旧约束设计的做法延续到新环境"的惯性；找到成本/性能/结构的真实下限。

# 四、适用场景

- 底层物理、经济、技术约束清晰可算（成本结构、物理极限、供需）
- 既有做法明显是为已消失的旧约束服务的
- 领域内反复失败、常规方法都试过了

# 五、不适用场景

- 领域成熟、试错成本高、自己没有基础知识——此时类比与抄成熟方案更优（见跨学科思维的判据）
- 时间极紧、只需够用的答案——从零推导太贵

# 六、使用方法

1. 写下问题涉及的所有"理所当然"
2. 对每条追问：它依赖的事实是什么？该事实今天还成立吗？
3. 只保留经得起追问的事实，从它们向上重建方案
4. 现实中多为混合用法：核心瓶颈处第一性，其余类比

# 七、相关工具

5 Why 追问法、成本结构拆解、马斯克五步工作法（质疑需求→删减→简化→加速→自动化）。

# 九、常见误区

- 为展示思考深度把一切还原到第一性——那是昂贵的表演
- 把"重新推导"做成"重新发明轮子"：推导前先确认轮子是否真的不适用
