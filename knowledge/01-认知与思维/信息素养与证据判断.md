# 一、定义

评估信息来源可靠性、区分证据强度等级、并在获取新证据时正确更新判断的能力。

# 二、核心原理

证据有强度阶梯：随机对照实验 > 大样本 observational 研究 > 单案例 > 专家意见 > 轶事。所有来源都有利益相关方向——先问"谁发布的、为什么发布"，再读内容。相关性 ≠ 因果性。

# 三、解决什么问题

被精心包装的软文/幸存者偏差样本误导；把相关当因果；用单案例推翻统计规律（或反之）。

# 四、适用场景

- 任何基于外部信息做决策的场合（选型、投资、市场判断）
- "我看到的结论可靠吗"的自检

# 五、不适用场景

- 信息成本高于信息价值时——S 级决策不必逐一核查来源
- 已有可靠一手数据时优先用自己的数据

# 六、使用方法

1. 三问来源：谁发布的？利益方向在哪？能否找到独立旁证？
2. 给证据分级，结论的确信度不得超过最强证据的级别
3. 主动找反例：搜"X 不成立/失败的案例"，而非只搜支持性信息
4. 新证据到达时按贝叶斯更新判断强度，不因单条新信息全盘翻转（也不拒绝更新）

# 七、相关工具

证据分级金字塔、SIFT 方法（停/调查/找更好来源/溯源）、贝叶斯更新。

# 九、常见误区

- 只搜集支持自己已有观点的证据（确认偏误的信息学形态）
- 把"发表在某平台上"当成"经过验证"
