# 一、定义

从多个学科提取底层逻辑（物理学的临界质量、生物学的生态位、心理学的激励、工程学的冗余……），构成多元思维模型网格，用最合适的模型分析眼前问题。

# 二、核心原理

单一学科像"拿着铁锤看什么都是钉子"。现实问题的结构千差万别，模型库越多元，越可能命中"这个问题的真实结构像哪个学科"。类比的价值在于结构相似，不在于表面相似。

# 三、解决什么问题

视角单一导致的盲区；本领域方法耗尽后的破局思路；对复杂问题的直觉校准。

# 四、适用场景

- 本领域常规方法失效，需要外部视角
- 问题的结构模式在别的学科有成熟理论（如把用户增长类比生态位竞争）

# 五、不适用场景

- 表面相似但结构不同的问题——坏类比比没类比更危险（如"公司像家庭"）
- 严格受控的专业领域（医疗、法律）——外部类比只能启发假设，不能替代专业结论

# 六、使用方法

1. 抽象出问题的结构骨架（是竞争？是反馈回路？是瓶颈？）
2. 扫描模型库：哪些学科的哪些模型有相同骨架？
3. 用类比生成假设，再用第一性原理验证——类比负责发现，不负责证明

# 七、相关工具

芒格多元思维模型清单、类比迁移法。

# 八、实际案例

芒格投资决策："我只想知道我会死在哪里，这样我就永远不去那里"——用逆向思维+多模型排除法。见 `knowledge/06-案例库/`。

# 九、常见误区

- 收集模型名词却从不使用——每个模型必须至少用过一次才算拥有
- 用表面相似（都是"网络"）而非结构相似做类比

# 十、相关知识

第一性原理（类比的验证器）、创造性思维（类比是创造的主要来源之一）。
