# 一、定义

以评估而非接受的态度处理主张：识别论点、论据、论证结构，检查假设与推理漏洞，区分事实与观点。

# 二、核心原理

一个主张的可靠性 = 论据的真实性 × 推理的有效性 × 假设的稳固性，任一环断裂则结论存疑。人的默认状态是确认偏误（只搜集支持性证据），批判性思维是对此的制度化抵抗。

# 三、解决什么问题

轻信权威/数据/多数意见；论证中的偷换概念、诉诸情感、滑坡谬误；把自己的直觉当事实。

# 四、适用场景

- 评估他人方案、报告、文章、数据结论
- 自己的结论产出前的最后一道自检

# 五、不适用场景

- 纯创意发散阶段——过度批判杀死想法
- 对人不对事的攻击——批判对象是主张，不是人

# 六、使用方法

1. 复述对方论证到能被对方认可的程度（防止批判稻草人）
2. 找出隐藏假设：结论成立需要哪些没说出口的前提？
3. 检查最强反对意见——"反对这个结论的最强理由是什么"（魔鬼代言人自检）
4. 结论按"确信程度"而非"对/错"输出

# 七、相关工具

魔鬼代言人、图尔敏模型（主张-根据-保证-支撑-限定）、常见谬误清单、认知偏误清单。

# 九、常见误区

- 为批判而批判：找到 flaw 就推翻全部——结论按确信度分级，不按二元
- 批判他人犀利、批判自己豁免——对等原则必须遵守
