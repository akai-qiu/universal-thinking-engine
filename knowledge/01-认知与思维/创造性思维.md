# 一、定义

生成超出既有选项集合的新方案的能力。核心是先发散（扩大选项空间）再收敛（结构化筛选），两个阶段必须分开。

# 二、核心原理

创造不是无中生有，是旧要素的新组合（联想距离越远、组合越新）。发散与收敛使用不同的心理模式：评价过早会扼杀发散，发散过久会消耗收敛建设性。

# 三、解决什么问题

方案同质化（只能在 A 和 B 之间选）；被既有约束的定义框死；创新停留在口号。

# 四、适用场景

- 探索性设计（新产品、新功能、新流程）
- 既有选项都不满意的岔路口
- 需要差异化竞争力的场合

# 五、不适用场景

- 执行阶段的优化任务——约束已定，守约比创造重要
- 高风险不可逆决策——创造出来的新方案也要过完整审查

# 六、使用方法

1. 发散：强制数量（先想 10 个再评价）、强制远距（随机词/跨行业类比）、反转约束（"如果预算翻十倍/砍到十分之一会怎么做"）
2. 收敛：按"与真实目标的契合度 × 可行性"矩阵筛选，不按新颖度筛选
3. 新颖且有潜力的方案进入实验库验证，不直接进入正式方案

# 七、相关工具

头脑风暴、SCAMPER（替代/合并/调整/修改/他用/消除/重排）、随机联想、约束反转。

# 九、常见误区

- 边发散边批判，10 分钟只剩 3 个平庸选项
- 把新颖当价值——新颖只是入场券，契合真实目标才算数
