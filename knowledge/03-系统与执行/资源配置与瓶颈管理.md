# 一、定义

识别当前系统中真正制约全局产出的那根短板（瓶颈），把资源集中投在瓶颈处与非瓶颈处明确区分的配置方法。

# 二、核心原理

约束理论（TOC）：系统的产出由最弱的环节决定。非瓶颈处的优化不提高整体产出，还常常因堆积在制品而伤害瓶颈。杠杆点是"小投入撬动全局"的干预位置——通常是瓶颈本身或信息流/激励结构。

# 三、解决什么问题

平均用力（资源撒胡椒面）；疯狂优化无关环节（因为瓶颈处的问题难，就去做容易但无关的事）。

# 四、适用场景

- 资源（时间/钱/人力）明确紧张的场合
- "很努力但整体没起色"的诊断

# 五、不适用场景

- 尚未识别系统全貌的早期——先摸清结构再找瓶颈
- 多个瓶颈并存且互不相干时——先确认哪个是真瓶颈

# 六、使用方法

1. 找瓶颈：哪一环节的积压/等待最长？产出最卡在哪？（看数据，不靠感觉）
2. 五步聚焦：识别瓶颈 → 充分利用瓶颈（不让它空转）→ 让其他环节迁就瓶颈 → 扩充瓶颈能力 → 回到第一步
3. 杠杆检查：本次投入的 20% 能否撬动 80% 的产出差异？不能则重新定位
4. 明确写出"本次刻意不优化什么"——非瓶颈清单与优化清单同样重要

# 九、常见误区

- 把"最紧急"当"最瓶颈"——紧急是时间属性，瓶颈是结构属性
- 瓶颈解除后不重新识别——旧瓶颈解除，新瓶颈会出现，优化是个循环
