# 一、定义

对重复发生的流程做标准化与自动化，释放人力到高判断环节。适用顺序：先删、再简化、再自动化——把坏流程自动化只会更快地产出坏结果。

# 二、核心原理

自动化放大流程的缺陷而非优点。频率 × 单次成本 > 自动化建设+维护成本，才值得自动化。马斯克五步法的次序是刻意设计的：删减在前，自动化最后。

# 三、解决什么问题

重复劳动占用高价值时间；人工流程的不稳定与遗漏；"忙但没产出"。

# 四、适用场景

- 高频重复、规则明确的操作（日报、构建、同步、格式转换）
- 流程已稳定、不再频繁变化的环节

# 五、不适用场景

- 低频任务——为一年三次的事写自动化是负收益
- 规则仍在快速演化的流程——先让规则稳定
- 高判断含量的环节（审美、策略）——自动化只能处理机械部分

# 六、使用方法

1. 流程盘点：列出每周重复 ≥2 次的操作，估算频率 × 单次耗时
2. 先问能否删除或简化（合并步骤、砍掉无人读的产出）
3. 再自动化 Top 项，写清异常处理路径（自动失败时谁、如何接手）
4. 自动化物也需要维护——记录归属与失效检查方式

# 九、常见误区

- 为"看起来酷"自动化低价值流程
- 自动化异常路径缺失——机器静默失败比人失败更难察觉
