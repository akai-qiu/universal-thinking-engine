# 06-案例库

真实任务的应用案例。每完成一个 M/L 级任务后，按复盘 AAR 的产出在此归档。

## 条目模板

```markdown
---
id: case-YYYYMMDD-001
title: 案例标题
date: YYYY-MM-DD
task_type: 问题类型（对应方法论地图的路由表）
scale: M / L
methods_used: [本次实际调用的知识条目]
outcome: 成功 / 失败 / 部分成功
---

# 背景
任务是什么，约束是什么。

# 过程
调用了哪些方法，每个方法的实际效果。

# 结果与归因
结果如何；差异归因到运气 / 判断 / 执行。

# 提炼
产出什么规则（进入实验库验证），或补充了哪条已有知识的适用边界。
```

## 规则

- 失败案例与成功案例同样入档，优先归档失败案例
- 案例是规则的证据来源：实验库中的 Experimental 条目必须能引用案例
