# 一、定义

立足现在、推演未来：根据长期目标制定阶段性路径，并为多种可能的未来留出对冲空间。

# 二、核心原理

未来不是单一剧本。战略 = 在不确定中找到不随情景变化的部分（不变量）重点投入，同时对高影响的分岔口准备多情景预案。终局思维提供方向，情景规划提供弹性。

# 三、解决什么问题

只顾眼前的短视方案；把单一预测当确定的赌注；宏大目标落不了地。

# 四、适用场景

- L 级长期规划（产品路线、职业规划、架构选型）
- 资源投入周期长、试错成本高的领域

# 五、不适用场景

- 短周期可逆任务——过度推演未来是拖延的高级形式
- 环境每季度剧变的领域——规划周期应缩短到与变化速度匹配

# 六、使用方法

1. 终局倒推：站在 5-10 年后的目标状态反观当下，问"那时回头看，今天最该开始积累什么能力？"
2. 不变量分析：未来 10 年几乎不变的东西（用户对可靠/便宜/快的偏好），向它下重注
3. 情景规划：识别 2-3 个高影响分岔，为每个写"信号 + 应对"，而非只押最优剧本
4. 阶段化：路径切成阶段，每阶段有准入条件与止损点，不可逆动作推迟到最后

# 九、常见误区

- 前瞻变成科幻写作——每个情景必须落到"出现什么信号就做什么"
- 长期规划一次性做完锁死——规划是滚动更新的，不是刻在石头上
