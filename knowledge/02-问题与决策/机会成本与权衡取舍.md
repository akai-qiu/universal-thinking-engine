# 一、定义

任何选择的真实成本是"为此放弃的最优替代方案"。现实没有完美解，只有权衡解——分析的任务是让每个方案写下它放弃了什么。

# 二、核心原理

没有成本陈述的方案是没有被认真设计过的方案。方案 A 看起来全面优于 B，通常是因为 A 的代价没写出来（转移到了别处：隐性债务、维护成本、机会损失）。

# 三、解决什么问题

"全都要"式的假方案；隐性成本在执行期才爆雷；取舍被藏在技术细节里无人审视。

# 四、适用场景

- 任何方案对比（M/L 级的设计与审查阶段）
- 资源分配决策

# 五、不适用场景

- S 级选择——直觉即可，显式权衡是仪式
- 成本可忽略且可逆的选择

# 六、使用方法

1. 每个方案强制写三行：得到什么 / 放弃什么 / 代价转嫁到了哪里（谁、何时承受）
2. 用机会成本重述选项："选 A 等于放弃 B + C"，让放弃可见
3. 速度-质量-成本三角：确认本次任务的真实约束主轴，另两维让步
4. 检查"两个好处全拿"的方案——它把代价藏在了哪？

# 七、相关工具

机会成本核算、三角权衡（速度/质量/成本）、十倍/十分之一推演（约束极端化暴露代价）。

# 九、常见误区

- 只算显性成本（钱、时间），忽略隐性成本（注意力、信任、技术债）
- 把"折中"当稳妥——有时最优解在极端（all-in 某一维），折中只是回避决策
