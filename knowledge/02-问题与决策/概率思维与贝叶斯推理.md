# 一、定义

不看绝对的对错，看概率；结论以确信度而非真伪表达，并随新证据按贝叶斯规则更新。

# 二、核心原理

世界大部分事件是随机的，确定性判断本质上是 100% 置信的赌注。后验概率 = 先验概率 × 新证据的似然比。强证据大幅更新，弱证据微幅更新，垃圾证据不更新。

# 三、解决什么问题

二元化思维（对/错、成/败）导致的脆弱决策；新信息出现后"辩论立场"而非"更新判断"；预测过于自信。

# 四、适用场景

- 高不确定性环境（市场、新技术、竞争格局）
- 预测与校准（估算时间、成功率、转化率）

# 五、不适用场景

- 数学/逻辑上可精确推导的问题——直接算，别估概率
- 用户需要明确决断时——概率语言要翻译成明确建议再交付

# 六、使用方法

1. 输出判断时附确信度："我认为 X，置信度 70%"
2. 预先写下"什么证据会让我下调/上调这个判断"——防止事后合理化
3. 新证据到达：问"这条证据把概率推了多少"，更新结论而不是辩护
4. 校准训练：事后对比预测与实际，统计自己 70% 置信的事是否真有 ~70% 发生

# 九、常见误区

- 用概率语言逃避决断："各有道理"不是分析，是放弃
- 单条戏剧性新闻就大幅翻转长期判断（新闻强度 ≠ 证据强度）
