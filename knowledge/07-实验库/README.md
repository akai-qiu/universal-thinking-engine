# 07-实验库

正在验证中的新方法与新规则。知识从"想法"到"正式入库"的必经中转站。

## 条目模板

```markdown
---
id: exp-YYYYMMDD-001
title: 实验名称
hypothesis: 假设（新方法能解决什么问题）
based_on: 来源案例或理论
started: YYYY-MM-DD
status: testing / confirmed / refuted
---

# 验证计划
在什么任务上试用，怎么判断有效。

# 验证记录
- YYYY-MM-DD：第 N 次试用，结果如何

# 结论
confirmed → 提炼为知识条目，送审进入正式知识库
refuted → 记录失败原因，移入 09-废弃知识 或改写假设重新开轮
```

## 规则

- 一个假设至少经过 2 次真实任务验证才能 confirmed
- 实验可以失败，失败本身是有效产出
