# 08-待审核知识

等待用户审批的新知识与修订提案（状态机中的 pending_review 阶段）。AI 只有提议权，审批权在用户。

## 送审前提：晋级五问（全部满足才可提交）

1. 是否经过真实任务验证（不是思想实验）？
2. 是否具备重复性（不同情境下有效）？
3. 是否明确了适用条件和失效边界？
4. 是否通过反例审查（主动找过它失败的情形）？
5. 是否比现有知识产生增量价值（不是已有条目的换皮）？

注意：同一规则 ≥2 次复用有效只是**候选资格**，不是有效性证明。

## 流程

1. AI 将新提炼的知识（来自实验库 confirmed）或对现有条目的修订放入本目录
2. 每条附提案说明：改什么、为什么改、依据是什么
3. 用户审阅后：批准 → 移入正式知识库对应目录（status: validated）；否决 → 退回实验状态或移入 09-废弃知识 并记录原因

## 条目模板

```markdown
---
id: pending-YYYYMMDD-001
type: 新增 / 修订
target: 目标条目 id（修订时填写）
submitted: YYYY-MM-DD
---

# 提案内容
（完整的知识条目或修订 diff）

# 依据
案例引用、验证记录、理论来源。
```
