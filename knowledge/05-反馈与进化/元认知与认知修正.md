# 一、定义

"对思考的思考"：监控自己的认知过程——我现在的判断基于什么？我的偏误在哪？我的思考质量如何？并据此修正。

# 二、核心原理

元认知是防偏误的最后一道防线：所有偏误（沉没成本、确认偏误、过度自信）的共同特征是当事人察觉不到。制度化自检问题可以在偏误生效前拦截它。

# 三、解决什么问题

沉没成本绑架（因已在 A 上花了时间而拒绝更优的 B）；确认偏误；过度自信（时间/成功率估算不打折）；思路僵化不自知。

# 四、适用场景

- 决策前的偏误自检
- 拿到新信息、要不要改主意的时刻
- 复盘中的归因环节

# 五、不适用场景

- 过度内省导致决策瘫痪——自检要限时，结论落地就停止

# 六、使用方法

决策前三问：
1. 沉没成本检查："如果今天从零开始，我还会选 A 吗？"
2. 确认偏误检查："我搜集的证据里有没有反对项？比例多少？"
3. 过度自信检查："我的估算打对折后，方案还成立吗？"
4. 日常校准：统计自己过去预测的命中率，建立个人的校准曲线

# 七、相关工具

偏误清单（卡尼曼/西博尼）、校准训练、决策日志。

# 九、常见误区

- 用元认知给自己找新理由——自检的标准答案是行为改变，不是"我想通了"
- 只在重大决策用——小决策的偏误累积起来同样昂贵
