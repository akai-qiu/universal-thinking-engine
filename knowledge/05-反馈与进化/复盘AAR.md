# 一、定义

任务结束后对照预期与现实的四问复盘：预期什么 → 实际什么 → 为什么有差异 → 哪条值得变成规则。美军 After-Action Review 的民用化。

# 二、核心原理

复盘质量取决于两个纪律：① 对比的是"事前写下的预期"，不是事后重建的预期（否则记忆会自我美化）；② 区分运气与判断力——结果好不等于决策好，反之亦然，只有过程质量才能改进。

# 三、解决什么问题

经验不复盘就只是经历；同样的坑掉两次；只庆祝成功不提取方法。

# 四、适用场景

- L 级任务必做，M 级择要复盘，S 级跳过
- 预测类任务（估算、判断）的校准训练

# 五、不适用场景

- 事情还在进行中——中途对进度可以，正式复盘等尘埃落定
- 情绪激烈期——先冷静再复盘，否则复盘变成甩锅大会

# 六、使用方法

1. 调出事前记录的预期（方法论地图路线、目标树、风险清单）
2. 四问逐项对比，差异点标注"运气 / 判断 / 执行"三类归因
3. 第 4 问产出具体规则："下次遇到 X 情况做 Y"，禁止"要更谨慎"式空话
4. 值得沉淀的规则写入本 skill 的进化记录与知识库（按自我进化机制的流程）
5. 失败案例与成功案例同样有价值，优先沉淀失败案例

# 七、相关工具

AAR 四问模板、归因三分法（运气/判断/执行）、决策日志。

# 九、常见误区

- 复盘变成表功会或批斗会——对象是决策过程，不是人
- 产出"感想"而不产出"规则"——检验标准：这条结论下次能用吗？
