# 一、定义

用数据而非感受判断方案效果：事前定义指标与判据，事后按判据评估。核心是防止"感觉变好了"替代"事实变好了"。

# 二、核心原理

指标必须在行动前定义——事后选指标会天然选到好看的（樱桃采摘）。单一指标必被博弈（古德哈特定律），要用小指标组互相制衡：主指标 + 反向指标（如增长 + 留存、速度 + 质量）。

# 三、解决什么问题

凭感觉宣布成功；指标被优化但目标没达成（虚荣指标）；改进无从判断。

# 四、适用场景

- 迭代与 MVP 的验证环节
- 任何声称"优化/提升/改善"的结论评估

# 五、不适用场景

- 无法量化的价值（审美、信任）——用代理指标时明确标注其局限
- 样本太小撑不起统计判断——诚实标注"样本不足，按个案处理"

# 六、使用方法

1. 事前写三行：主指标 / 反向指标（防博弈）/ 判断标准（变化多少算成功）
2. 设基线：没有基线的数据无法判断变化
3. 事后按判据评估，不达标也如实记录——失败数据与成功数据同样入库
4. 定期审视指标本身：它还在为目标服务吗？（古德哈特检查）

# 七、相关工具

北极星指标、A/B 测试、基线对比、古德哈特定律自检。

# 九、常见误区

- 只看主指标不看反向指标——留存崩了的增长是漏桶注水
- 用绝对值替代比率，或反之——按指标性质选择
