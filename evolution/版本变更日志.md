## v1.2 · 2026-11-07

**依据**：用户提供的《UTAE V1.2 核心 Skill 升级任务书》（外部评审意见），经主 agent 评估后裁剪执行——六项任务采纳五项，拒绝六引擎平行架构（职责映射并入总体架构条目，不新建体系）。

**新增**：
- `system/protocols/` 五份运行协议：task-routing（五维评分+强制升级）、method-selection（最小充分原则+停止条件）、dynamic-iteration（五类失效回退映射+停止条件）、knowledge-lifecycle（pending_review 状态机+晋级五问）、capability-boundary（平台能力诚实条款）
- `tests/validate.py`：知识库结构校验器（frontmatter/状态合法性/id 唯一/category 匹配/related 引用/关键节检查），当前 0 错误 0 警告
- `tests/evals.json`：8 个结构性回归测试用例（S 级陷阱/M 级选择/L 级不可逆/方法堆砌陷阱/复杂分析/对抗审查/知识缺口/用户纠正）
- `knowledge/05-反馈与进化/自我进化机制.md`：v1.0 计划遗漏的条目，本次补建

**修改**：
- SKILL.md：v1.2——分流升级为五维评分、加入最小充分原则与回退映射摘要、进化机制补晋级五问与 pending_review、能力诚实条款
- `00-核心框架/方法论地图.md` → v1.2：分级规则替换为五维评分
- `00-核心框架/总体架构.md` → v1.2：补充回退映射与职责映射说明
- viewer app.js/styles.css：支持 pending_review 状态显示与统计；知识地图纳入 pending_review 节点

**修复**（validate.py 首跑发现）：

- "8 项指标客观评分"（方法论输出以结构性断言验证，不做虚假量化）
